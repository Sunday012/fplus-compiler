# Code of Conduct

## Our Standard

We want F+ to be a welcoming project for contributors of every background and
experience level. Be respectful, constructive, patient, and considerate in
issues, pull requests, reviews, and other project discussions.

Unacceptable behavior includes harassment, discrimination, personal attacks,
deliberate intimidation, publishing another person's private information, and
disrupting project discussions.

## Enforcement

Project maintainers may edit or remove contributions and comments that do not
follow this standard. They may temporarily or permanently restrict
participation when behavior is inappropriate, threatening, or harmful.

Report conduct concerns privately to the repository owner through their
GitHub profile. Reports will be reviewed as promptly and confidentially as
possible. Maintainers who are involved in a report must not participate in
resolving it.

This code applies in project spaces and when someone is publicly representing
the project.
